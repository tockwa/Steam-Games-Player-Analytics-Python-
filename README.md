# 🎮 Steam Games Player Analysis (Data Analytics Project)

## 📌 Project Overview

This project analyzes **Steam (Valve) games player statistics** using **Python, Pandas, Matplotlib, and Seaborn**.
The dataset contains monthly player data for multiple games, including **average players, peak players, and dates**.

---

## 📂 Dataset

The dataset includes the following columns:

* `Date` – monthly timestamp
* `Game_Name` – game title
* `Avg_players` – average players per month
* `Peak_Players` – peak players per month
* `Gain`, `Percent_Gain` – monthly change metrics

---

## 🔍 Analysis Performed

* **Peak Players by Year** (maximum peak per year)
* **Average Players by Year** (mean yearly activity)
* **Top 10 Games of All Time** (based on highest average players)
* **Seasonal Analysis** (Winter, Spring, Summer, Autumn)
* **Most Popular Season per Year**
* **Top Game for Each Season of Each Year**

All results are visualized using bar charts and summarized in clean tables.

---

## 🛠️ Tools & Technologies

* Python
* Pandas
* Matplotlib
* Seaborn

---

## 📊 Key Insights

* Identified years with the highest peak and average player activity
* Determined the most popular games across all time
* Discovered which **season dominates player activity each year**
* Selected the **top-performing game** for every dominant season
